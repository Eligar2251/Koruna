# ЦСБ — Центральная Строительная База

Сайт на Next.js. Публичные страницы — те же макеты, с новым названием, цветом и фотографиями. Разделы и товары добавляются в админке и появляются на страницах каталога.

## Сайт и админка

```bash
npm install
cp .env.example .env   # SUPABASE_URL и SUPABASE_ANON_KEY
npm run build
npm start              # http://localhost:3000
```

Админка: http://localhost:3000/admin

Нужны только адрес проекта и anon-ключ. Строка подключения к Postgres и service role в сайт не входят: service role обходит защиту строк, а прямое подключение к базе обходит её целиком.

Пароль администратора задаётся в Supabase → Authentication. Сайт пароль не хранит. После входа Supabase выдаёт JWT, сервер проверяет его у Supabase и кладёт в HttpOnly-куку. В браузер ключ базы не отдаётся.

Пока в `.env` нет настоящих ключей, витрина пустая, а вход в админку закрыт.

## База Supabase

Миграции в `supabase/migrations/` применяются по порядку в SQL Editor:

1. `20261017120000_clean_database.sql` — очищает схему `public`. Не удаляет файлы S3 и пользователей Authentication.
2. `20261017120100_catalog.sql` — разделы, товары, `admin_users`, бакет фото.
3. `20261017130000_harden_catalog.sql` — закрывает чтение скрытых строк, запись в админы и список файлов бакета.

Повторно запускать очистку после наполнения каталога нельзя.

В Authentication лучше выключить открытую регистрацию. Админа добавляют так:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'admin@example.ru';
```

Самостоятельно вписать себя в `admin_users` через anon-ключ нельзя.

## Что закрыто

- Гость видит только опубликованные разделы и товары.
- Писать в каталог может только JWT пользователя из `admin_users`.
- Подделать JWT на сервере нельзя: подпись проверяет Supabase.
- Список администраторов и список файлов бакета наружу не отдаются.
- Имена фото случайные, тип и размер ограничены.
- Ошибки базы клиенту не показываются.
- Кука сессии недоступна скриптам страницы. Чужой сайт не может отправить запрос на изменение без специального заголовка, который браузер на чужом сайте не пропустит.
- Попытки входа ограничены.

Ручная очистка Storage через API, если она ещё нужна: `npm run clean:dry`. Ей по-прежнему нужна строка подключения, сайт её не использует.
