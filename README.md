# ЦСБ — Центральная Строительная База

Сайт на Next.js. Страницы — React, у каждой свой файл стилей. Разделы и товары задаются в админке и показываются в каталоге. Корзина и оформление заказа работают на сайте.

## Запуск

```bash
npm install
cp .env.example .env
npm run build
npm start
```

Админка: http://localhost:3000/admin

Если `SUPABASE_URL` и `SUPABASE_ANON_KEY` не заданы, каталог, заказы и администраторы пишутся в `data/`. Первый администратор берётся из `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Пароль в файл не записывается открытым текстом: хранится JWT с односторонним ключом. Сессия — отдельный JWT в HttpOnly-куке `csb_access`.

Когда ключи Supabase заданы, вход идёт через Supabase Auth. Назначить нового администратора можно из админки: сервер создаёт пользователя и вызывает `grant_admin`. Для этого в Authentication нужно выключить подтверждение почты, иначе новый админ не войдёт, пока письмо не подтверждено. Открытую регистрацию лучше выключить: назначение идёт только из уже открытой админки.

Строка подключения к Postgres и service role в сайт не входят.

## База

Миграции в `supabase/migrations/` применяются по порядку:

1. `20261017120000_clean_database.sql` — очищает схему `public`.
2. `20261017120100_catalog.sql` — разделы, товары, `admin_users`, бакет фото.
3. `20261017130000_harden_catalog.sql` — закрывает скрытые строки, запись в админы и список файлов.
4. `20261017140000_orders_staff.sql` — заказы, `password_key`, назначение администратора.
5. `20261017140100_seed_catalog.sql` — базовые товары. Повторный запуск не затирает изменённые строки.

Повторно запускать очистку после наполнения каталога нельзя.

## Что закрыто

- Гость видит только опубликованные разделы и товары.
- Писать в каталог может только администратор.
- Пароль из `password_key` не восстанавливается. Ключ не принимается как сессия.
- Список ключей и список файлов бакета наружу не отдаются.
- Заказы гость может создать, но не прочитать.
- Кука сессии недоступна скриптам страницы. Чужой сайт не меняет каталог без заголовка `x-csb-request`.
- Попытки входа и заказы ограничены по частоте.
