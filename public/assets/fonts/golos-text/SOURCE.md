# Golos Text — локальные файлы

Российская гарнитура Paratype (Александра Королькова, Виталий Кузьмин), созданная для сайтов государственных и общественных сервисов. Кириллица включена во все четыре начертания.

- Российский издатель: https://www.paratype.ru/
- Проект: https://www.paratype.ru/fonts/pt/golos-text
- Файлы получены из открытого репозитория проекта: https://github.com/googlefonts/golos-text/tree/main/fonts/webfonts
- Лицензия: SIL Open Font License 1.1, файл OFL.txt рядом.

Браузер загружает шрифты только с собственного домена сайта (`/assets/fonts/`), а не с Google Fonts или других внешних сервисов. Загрузка непосредственно с .ru в среде разработки недоступна; источник файлов указан явно, без подмены происхождения.
